# Portal One

面向企业品牌展示与咨询线索获取的可运营门户模板。它将面向访客的企业官网与供运营人员使用的管理端放在同一项目中，适合用作贸易、供应链、制造、专业服务等企业的官网起点。

仓库内置的商贸行业内容仅用于演示信息结构和页面效果；上线前可通过管理端替换为任意企业的品牌、文案、案例、联系方式与媒体素材。

## 它解决什么问题

企业门户通常既要讲清楚“我们是谁、能做什么、做过什么”，也要让潜在客户有明确的联系入口。Portal One 将这两件事整理为一套可维护的内容与转化流程：

1. 访客从首页快速了解企业定位、业务能力、优势和案例。
2. 访客按需查看业务、服务和案例详情，确认服务范围与交付能力。
3. 访客通过电话、邮箱、地图或在线留言发起咨询。
4. 运营人员在管理端更新对外内容、控制页面展示，并跟进或导出咨询线索。

## 产品内容

### 前台门户

- 首页：Hero 轮播、核心业务入口、数据统计、企业简介、优势与服务流程、服务项目、案例展示和咨询引导。
- 企业介绍：公司简介、组织架构与成长历程，帮助访客建立对企业规模和背景的认知。
- 主营业务与服务项目：列表页与详情页模板，详情页可组织概述、服务范围、流程、优势与常见问题。
- 案例展示：以行业背景、需求、方案和成果呈现可复用的服务能力。
- 联系我们：地址、电话、邮箱、地图入口与在线留言表单；移动端支持直接拨号和发邮件。
- 双语访问：默认中文站，英文站可独立开启或关闭；未翻译字段会自动使用中文内容，便于逐步完善国际化内容。
- 响应式体验：导航、内容布局和联系入口适配桌面与移动设备。

### 管理端

| 场景 | 可完成的工作 |
| --- | --- |
| 内容维护 | 新增、编辑、排序和上下线主营业务、服务项目与案例展示。 |
| 页面配置 | 维护首页、企业介绍、站点信息及页面搜索信息。 |
| 导航与展示 | 调整导航名称、链接和顺序；按需隐藏首页区块、底栏信息或联系渠道，而不删除内容。 |
| 多语言内容 | 分别维护中文和英文内容，并控制英文站是否对外开放。 |
| 媒体素材 | 上传图片和视频；可使用本地存储或配置对象存储。 |
| 线索管理 | 查看联系表单提交的咨询信息，按状态跟进、筛选、删除或导出 Excel 可直接打开的 CSV。 |

## 适用方式

- 作为新企业官网的基础模板，先替换演示内容，再根据品牌视觉调整页面素材。
- 作为已有官网的内容管理入口，由运营人员维护业务、案例和联系渠道，无需每次修改页面代码。
- 作为中英文企业介绍站，将英文内容按页面或条目逐步补齐后再开放英文入口。

## 演示数据

仓库不会提交 SQLite 数据库或上传目录。`just local` 在首次运行时根据 `web/src/mock/zh` 与 `web/src/mock/en` 创建数据库，写入虚构的“远岚供应链 / FARLANE DEMO”双语内容。

演示首页、业务、服务、案例和关于页面均配有本地图片，核心场景同时配有 WebM 视频；初始化和浏览不依赖外部图片服务。演示媒体采用 CC0 1.0，具体说明见 [媒体许可证](./web/public/demo/media/MEDIA_LICENSE.md)。

## 本地运行

### 前置条件

- Node.js 20 或更高版本
- npm
- 可选：[just](https://github.com/casey/just) 命令运行器，用于热更新开发与服务器部署

### 一键运行

下载源码后，在项目根目录执行：

```bash
npm install
npm start
```

首次执行 `npm start` 会构建前台与管理端、初始化 SQLite 演示数据和管理员，然后用一个 Node 进程启动三端。随后访问：

- 门户：<http://localhost:3000/>
- 管理端：<http://localhost:3000/admin/>

### 初始化管理员

管理员初始凭据仍由 `justfile` 统一定义。默认账号为 `admin`，默认密码为 `admin123`，因此全新克隆项目可直接执行 `npm start` 后登录管理端。

部署正式环境或需要自定义账号时，可在执行命令前通过环境变量覆盖默认值：

```bash
ADMIN_USER=portal-admin ADMIN_PASSWORD='choose-a-strong-password' npm start
```

若需要重新生成演示数据和管理员账号，执行：

```bash
ADMIN_USER=portal-admin ADMIN_PASSWORD='choose-a-strong-password' npm run seed
```

`npm run seed` 会重置演示业务内容、站点配置和管理员账号，请不要在已有正式内容的环境中直接执行。

### 从 npm 安装

包发布到 npm 后，可在空目录中安装并运行：

```bash
npm install portal-one
npx portal-one
```

也可以全局安装：

```bash
npm install --global portal-one
portal-one
```

npm 安装包已经包含构建后的门户和管理端，不会在用户机器上重新构建。SQLite、上传文件和配置默认保存在执行命令目录下的 `portal-one-data/`，升级 npm 包不会覆盖该目录。可通过 `PORT` 和 `PORTAL_DATA_DIR` 修改端口与数据位置。

### 前后端热更新开发

```bash
just dev
```

启动后访问：

- 门户：<http://localhost:5173/>
- 管理端：<http://localhost:5174/admin/>
- 接口服务：<http://localhost:3000/api>
