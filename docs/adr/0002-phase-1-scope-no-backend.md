# 一期不做任何自建后端，线索通过第三方表单与直拨通道收集

**Status**: 已被 ADR-0003 部分取代（2026-07-22）——自建后端与管理端落地，留言线索改自托管。

一期范围明确排除：在线下单、会员系统、订单查询、后台管理、新闻中心、多语言。转化路径仅三条——留言表单、电话直拨、在线客服（QQ/微信）。留言表单不接自建后端，使用第三方表单服务（金数据/麦客）或 serverless 函数转发到企业邮箱/企业微信。

**Why**: 参考站联索（同等体量）即为此形态；自建后端意味着备案之外还有等保、运维、安全成本，对一个宣传站不成比例。把"不做"写清楚是为了防止二期前有人顺手加半个后台。

**Consequences**: 表单数据留存在第三方服务中，需在隐私政策中声明；二期若要新闻中心/英文站，需重新评估是否引入 CMS 与 i18n 构建管线（技术上已预留内容集合与路由结构）。
